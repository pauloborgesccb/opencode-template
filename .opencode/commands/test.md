description: Roda os testes do projeto e corrige as falhas
---

Rode a suíte de testes deste projeto.

Alvo: $ARGUMENTS

Se o alvo estiver vazio, rode a suíte inteira. Se vier um caminho ou nome de teste, rode apenas ele.

Para cada falha:

1. Mostre a saída real do teste.
2. Diagnostique a causa raiz antes de editar.
3. Corrija o código de produção, não o teste, a menos que o teste esteja errado. Nesse caso, explique por quê.
4. Rode de novo até passar.

Não altere testes só para fazê-los passar.
