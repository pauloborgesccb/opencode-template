---
description: Monta o commit das mudanças atuais seguindo o padrão do repositório
---

Prepare um commit das mudanças em staging e working tree.

Passos:

1. `git status` e `git diff` para ver o que mudou.
2. `git log -10 --oneline` para seguir o padrão de mensagem do repositório.
3. Agrupe as mudanças em um commit coeso. Se houver mudanças sem relação entre si, avise antes de seguir.
4. Escreva a mensagem no padrão observado no histórico.
5. Não faça push.

Contexto extra: $ARGUMENTS
